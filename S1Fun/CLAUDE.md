# S1Fun/

Functions on the circle. `@S1Fun` is the abstract base, `@S1FunHandle` and `@S1FunHarmonic`
(Fourier coefficients, `S1KernelFunctions/`) the representations. Same abstract-interface
pattern as `SO3Fun/CLAUDE.md`. Used for angular profiles and sections through ODF or pole
figure data rather than as a primary data type.
